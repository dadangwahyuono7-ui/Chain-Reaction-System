CARA CEK MASIH JALAN / ADA ERROR
------------------------------------------------------
Karena semua hidden, kalau mau tau ada error atau nggak, cek
file log ini (buka pakai Notepad biasa):

   D:\PROJECT TRADING\bookmap-bridge\udp_listener.log
   D:\PROJECT TRADING\bookmap-bridge\dashboard_web.log
   D:\PROJECT TRADING\tradingview-mcp-jackson\tv_poll.log

Kalau udp_listener.log baris terakhir keliatan "trades=xxx
H4=... rec=..." dan angkanya terus nambah tiap beberapa detik
- berarti sehat, lagi jalan normal.

Cek proses yang lagi jalan (PowerShell):
   Get-CimInstance Win32_Process | Where-Object { $_.CommandLine -like '*udp_listener.py*' -or $_.CommandLine -like '*tv_poll.mjs*' -or $_.CommandLine -like '*dashboard_web.py*' }

(Catatan: tiap script bakal nongol SEBAGAI 2 PROSES - itu normal,
cara kerja venv Python di Windows, bukan berarti dobel/nyangkut.)


TROUBLESHOOTING SINGKAT
------------------------------------------------------
- Dashboard nunjukin "WAIT" terus / TF matrix kosong semua
  -> tv_poll.mjs belum kebaca chart-nya. Cek tv_poll.log, kalau
     ada "No TradingView chart tab found" berarti chart Pine-nya
     belum kebuka di TradingView (buka manual chart GCZ6/XAUUSD).

- Dashboard gak nampilin data order flow (Wall Area kosong, Pulse 50%)
  -> Bookmap belum connect Rithmic, atau addon bookmap_bridge.py
     belum ke-load di chart yang aktif.

- dashboard_web.log ada error "No module named 'webview'"
  -> Salah python yang dipake, harus venv:
     D:\PROJECT TRADING\venv\Scripts\python.exe
     (START_TRADING.bat udah di-set bener, ini cuma relevan
     kalau jalanin manual)

- Port 9000 conflict (UDP Listener gak mau start / gak nerima data)
  -> Ada proses lain yang pakai port 9000 (misalnya
     wall-breakout-engine punya backend). Jalanin STOP_TRADING.bat
     dulu, cek gak ada proses nyangkut, baru START_TRADING.bat lagi.

- Abis Claude Code edit logic engine (cmp_engine.py,
  cr_master_engine.py, market_pulse_engine.py, dll), HARUS
  STOP_TRADING.bat lalu START_TRADING.bat lagi biar logic
  baru kepake.
